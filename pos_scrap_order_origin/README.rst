This module extends **POS Scrap Order** to require a **Scrap Reason
Tag** when creating a scrap order from the Point of Sale screen.

Key features:

-  **Mandatory reason tag**: cashiers must select a reason tag before
   the scrap order is created.
-  **Per-POS configuration**: each POS can have its own list of allowed
   reason tags.

Configuration
=============

1. Go to **Inventory → Configuration → Scrap Reason Codes** and create
   the reason codes you want to make available in POS.

   Each reason code can optionally define a **Scrap Location**
   (overrides the default destination) and restrict usage to specific
   **Product Categories**.

2. Go to **Point of Sale → Configuration → Point of Sale**, open your
   POS and:

   -  Set **Scrap Order Option** (e.g. *Always create Scrap Order*).
   -  Add the allowed reason codes in the **Scrap Origin** field.

Usage
=====

1. Open your Point of Sale session.
2. Add products to the current order.
3. Click **Make Scrap Order** in the control buttons area.
4. On the Scrap screen, select a **Reason Code** from the list.
5. Click **Create Scrap Order** to confirm.

The products will be moved to the scrap location associated with the
selected reason code.

**Error cases**

-  If no reason code is selected, the scrap order is rejected with an
   error message.
-  If the selected reason code is not allowed for the product's
   category, a *User Error* is shown and no scrap is created.
