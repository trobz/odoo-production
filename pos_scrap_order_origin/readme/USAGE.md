1. Open your Point of Sale session.
2. Add products to the current order.
3. Click **Make Scrap Order** in the control buttons area.
4. On the Scrap screen, select a **Reason Code** from the list.
5. Click **Create Scrap Order** to confirm.

The products will be moved to the scrap location associated with the selected
reason code.

**Error cases**

- If no reason code is selected, the scrap order is rejected with an error message.
- If the selected reason code is not allowed for the product's category, a
  *User Error* is shown and no scrap is created.
