1. Go to **Inventory → Configuration → Scrap Reason Codes** and create the
   reason codes you want to make available in POS.

   Each reason code can optionally define a **Scrap Location** (overrides the
   default destination) and restrict usage to specific **Product Categories**.

2. Go to **Point of Sale → Configuration → Point of Sale**, open your POS and:

   - Set **Scrap Order Option** (e.g. *Always create Scrap Order*).
   - Add the allowed reason codes in the **Scrap Origin** field.
