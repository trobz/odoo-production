Speed up the Point of Sale Orders Analysis report (Point of Sale >
Reporting > Orders).

By default the report aggregates the whole sales history each time it is
opened, which is slow on databases with many point of sale order lines.

This module opens the report filtered on the current month (Order Date
filter). Users can still remove the filter or select another period.
