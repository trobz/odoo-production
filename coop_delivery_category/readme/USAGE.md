This module adds delivery category functionality to the purchase system.

## Features

- Create and manage delivery categories
- Assign delivery categories to products
- Filter computed purchase orders by delivery categories

## Configuration

1. Install the module
2. Go to Inventory > Configuration > Delivery Categories to create categories
3. Assign delivery categories to products in the product form
4. In computed purchase orders, filter by delivery categories

## Requirements

- This module depends on:
  - `purchase`
  - `purchase_compute_order`
