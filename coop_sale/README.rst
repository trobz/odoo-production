This module gathers generic Sale Order view customizations shared by all
foodcoop instances.

Currently it:

- Hides the "Packaging Quantity" and "Packaging" columns in the sale
  order line list view by default (they remain available through the
  optional column selector).
- Moves the "Print Categories" and "Print Category Rules" menu items
  from *Sales > Products* to *Sales > Configuration*.
