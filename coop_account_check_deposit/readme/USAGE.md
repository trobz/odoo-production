## Configuration

1. Go to **Accounting > Configuration > Journals**
2. Create or verify a "Check Received" journal (code: CHK) for receiving customer checks

## Creating a Check Deposit

1. Go to **Accounting > Customers > Checks to Deposit**
2. Select the checks you want to deposit
3. Click **Create Deposit**
4. Fill in the required details:
   - **Deposit Date**: Date of deposit
   - **Journal**: Select the destination journal for the deposit
   - **Destination Journal**: Optionally specify a destination journal for the move lines
5. Click **Validate** to confirm the deposit

## Check Holder Name

When checks are deposited, the check holder name is automatically populated from the associated partner on the journal entries. This helps track who issued each check in the deposit.

## Deleting a Check Deposit

If you need to remove a check deposit:
1. Go to **Accounting > Customers > Checks to Deposit**
2. Find the deposit you want to delete
3. Delete the deposit record

**Note**: Deleting a deposit will also remove the associated journal entries.
