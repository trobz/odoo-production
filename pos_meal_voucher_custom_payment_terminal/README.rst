This module glues the Meal Voucher custom module with the Payment
Terminal module, ensuring compatibility when using meal vouchers as a
payment method through a payment terminal in the Point of Sale.

.. contents::
   :local:

Usage
=====

To use this module:

1. Install the Meal Voucher Custom and Payment Terminal modules.
2. Configure meal voucher payment methods and a payment terminal in the
   POS settings.
3. In the POS payment screen, select a meal voucher payment method with
   a payment terminal. The meal voucher amount will be processed through
   the terminal as usual.
