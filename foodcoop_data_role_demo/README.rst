Overview
--------

The "Demo Roles for Foodcoop" module provides demo users pre-configured
with each of the roles defined in the ``foodcoop_data_role`` module.
This module is intended for testing and demonstration purposes.

Usage
=====

Installation
------------

1. Ensure ``foodcoop_data_role`` is installed.
2. Copy this module to your Odoo addons directory.
3. Update the apps list.
4. Install the "Demo Roles for Foodcoop" module.

Usage
-----

After installation, 18 demo users are created — one per Foodcoop role.
These users can be used to test role-based access control without having
to manually create and configure test users.

Demo users have login emails in the format ``<role>@example.com``.
