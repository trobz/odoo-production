## Generate Gross Margin Report

1. Go to **Point of Sale > Reporting > Gross Margin**
2. Select the start date and end date for the report
3. Select the product categories to include in the report
4. Click **Export** to generate the XLSX report

The report will include:
- Sales amount
- Beginning inventory value
- Purchases
- Goods available for sale
- Ending inventory value
- Cost of Goods Sold (COGS)
- Gross Margin

Each category will be listed with its corresponding values.
