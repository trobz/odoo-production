Customize asset management behavior for food cooperatives.

This module extends ``account_asset_management`` to allow any journal
type (not only "General") to be selected on an asset profile, filtered
by company.

**Table of contents**

.. contents::
   :local:

Configuration
=============

No additional configuration is required beyond the standard
``account_asset_management`` setup.

When creating or editing an **Asset Profile**, the **Journal** field
will now show all journals belonging to the current company, regardless
of journal type.

Usage
=====

1. Go to **Accounting → Configuration → Asset Profiles**.
2. Open or create an asset profile.
3. In the **Journal** field, all journals of the current company are
   available for selection (not limited to "General" journals).
