This module extends ``website_sale_checkout_skip_payment`` to enable the
*Skip Payment* option by default for all partners.

When installed, the field ``skip_website_checkout_payment`` on
``res.partner`` is set to ``True`` by default, so new partners will
automatically bypass the payment step during the website checkout
process without requiring manual configuration.

Usage
=====

No additional configuration is required. Once installed, all new
partners will have the *Skip Website Checkout Payment* option enabled by
default.

To override this behaviour for a specific partner:

1. Go to *Contacts* and open the partner form.
2. Uncheck the *Skip Website Checkout Payment* field.
3. Save the record.

That partner will then go through the normal payment step during
checkout.
