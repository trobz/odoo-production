Export account move lines for accounting software.

This module allows you to export account move lines for external accounting software.

Usage
=====

1. Go to *Accounting > Exports > Export Moves*
2. Configure export options (date range, journals, partners, invoices)
3. Select export configuration
4. Click "Export" button to generate the XLSX report
5. The exported file will be attached and available for download

You can also configure export settings at:
- *Accounting > Journals > Export Settings* - Set export code per journal
- *Accounting > Exports > Export Configuration* - Configure export fields and formats
