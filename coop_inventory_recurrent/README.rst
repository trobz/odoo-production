Coop - Inventory Recurrent
==========================

This module provides recurring inventory management for food
cooperatives.

It allows users to:

-  Create and manage recurring physical inventory adjustments grouped by
   product category groups.
-  Print inventory reports for one or multiple inventory adjustments at
   once.

.. contents::
   :local:

Usage
=====

Usage
=====

1. Go to ``Inventory > Operations > Recurrent Inventories``.
2. Click the ``Execute`` to create inventory adjustments for selected
   category groups.
3. Select one or more inventory adjustments and use the
   ``Print Recurring Inventories`` action to generate inventory reports.
