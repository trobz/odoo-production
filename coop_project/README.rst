This module provides project management customizations for food cooperatives,
including kanban view enhancements with project category legends and calendar
event integration for project tasks.

**Table of contents**

.. contents::
   :local:

Installation
============

This module depends on:

* ``calendar``
* ``project``

Configuration
=============

No specific configuration is required.

Usage
=====

The module adds a custom kanban view for projects with a category legend panel,
allowing users to filter tasks by project category.
