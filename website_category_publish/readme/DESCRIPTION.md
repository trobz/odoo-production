Allow users to publish/unpublish eCommerce products by their category.

When a category is unpublished:

- All products belonging exclusively to unpublished categories are hidden from
  the shop.
- The category is removed from the shop sidebar.
- All child categories are automatically synchronized to the same published
  state as their parent.

A product is visible on the shop if it has no category assigned, or if at
least one of its categories is published.
