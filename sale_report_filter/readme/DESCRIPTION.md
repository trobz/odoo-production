This module enhances the Sales Analysis (Sale Statistics) report with improved filtering and default settings optimized for daily operations.

**Key Features**:

1. **Today Filter**: Adds a dedicated "Order Date: Today" filter that shows only sales from the current day
2. **Default Today View**: Automatically applies the Today filter when opening the Sales Analysis report
3. **Optimized Pivot Measures**: Pre-configures the pivot view with the most commonly used metrics:
   - Product quantity (units sold)
   - Total price (including taxes)
   - Subtotal (before taxes)
   - Record count

**Use Cases**:

- **Daily Sales Monitoring**: Quickly view today's sales performance without manually setting date filters
- **Real-time Analysis**: Monitor current day sales in real-time for operational decisions
- **Shift Reporting**: Generate end-of-day reports showing today's transactions
- **Food Cooperative Operations**: Ideal for cooperatives that need to track daily product movement and sales

This module is particularly useful for food cooperatives and retail operations where daily sales tracking is essential for inventory management, member services, and operational reporting.

The Today filter uses timezone-aware date calculations to ensure accurate filtering based on the user's local timezone.
