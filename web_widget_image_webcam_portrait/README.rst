This module extends the functionality of the image widget and allows to
take snapshots with WebCam in Portrait mode.

.. contents::
   :local:

Usage
=====

To use this module, you need to:

1. Install the module in your Odoo instance.
2. In any form view with an image field, the webcam capture button will
   appear in portrait orientation.
3. Click the capture button to open the webcam and take a snapshot.
4. The captured image will be saved in portrait format.
